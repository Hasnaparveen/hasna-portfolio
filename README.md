# Hasna Parveen T.P.K. — Portfolio

A responsive, cream-and-brown multi-page portfolio built with HTML, CSS, and a small amount of JavaScript.

## Files
- `index.html` — Home
- `about.html` — About and education
- `skills.html` — Current skills
- `projects.html` — DropWise and Scam Detection
- `experience.html` — Internship, hackathon, and contact
- `style.css` — Shared design and responsive styles
- `script.js` — Mobile navigation, year, and subtle reveal effects
- `assets/` — Add your profile photo, project screenshots, and resume here later

## Preview locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Before publishing
1. Add your profile photo and update the placeholder in `index.html` if desired.
2. Add project screenshots in `projects.html`.
3. Add certifications when ready.
4. Add a resume PDF if you want a resume download button. The button is not included yet because you chose to leave the resume for later.
5. Confirm all links and project descriptions are accurate.
6. Upload the folder contents to a GitHub repository and enable GitHub Pages in repository Settings → Pages.

## Notes
- The project descriptions distinguish prototypes/demonstrations from deployed products.
- Skill indicators are illustrative, not objective assessments.
- Google Fonts are loaded online; fallback fonts are included.
